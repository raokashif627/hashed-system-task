**Goal:** Build the Venuze marketplace frontend (Figma-accurate public site + reqres login + protected dashboard) for the Hashed System Next.js assignment.

## Review Focus

1. **Hydration flash / mismatch** — persisted auth and saved state must not render the logged-out top bar then flip, nor throw React hydration warnings. Test in Task 4 (`useHydrated`) and Task 7 (TopBar renders neutral placeholder before hydration).
2. **Cookie and store drift** — a user with a token in localStorage but no cookie (cookie expired/cleared) must not be stuck: middleware sends them to `/login`, and the store re-mirrors the cookie on rehydrate. Test in Task 4 (`onRehydrateStorage` resets cookie).
3. **`from` redirect safety** — `/login?from=https://evil.com` or `//evil.com` must redirect to `/dashboard`, not off-site. Test in Task 4 (`safeFrom`).
4. **Malformed search URL** — `?capMin=abc&guests=-5&types=Nope&sort=bad` must fall back to defaults, never crash or show NaN. Test in Task 3.
5. **Booking date edge** — requesting a booking for today is allowed; yesterday is rejected; guests above venue capacity rejected. Test in Task 11.
